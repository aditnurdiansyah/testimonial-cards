# Testimonial Cards

## Project Overview

This project involves creating a modern, accessible, and responsive **Testimonial Cards** component using semantic HTML and CSS. The primary objective is to present customer and user testimonials, ratings, and reviews in various card design layouts and slider structures.

The project focuses on building a semantic and accessible web component while applying essential frontend practices such as SEO meta tags, Open Graph (OG) integration for social sharing, favicon implementation, Google Fonts integration, and responsive CSS layout optimization.

## Project Requirements

* **Semantic HTML**
  Use semantic HTML elements to structure the testimonial cards and slider layouts cleanly and accessibly.

* **Search Engine Optimization (SEO) Meta Tags**
  Include essential metadata inside the section to improve discoverability and search engine indexing.

* **Open Graph (OG) Tags**
  Implement Open Graph tags to provide optimized previews when sharing links on social media platforms.

* **Favicon**
  Add a favicon for better branding and browser recognition.

* **Responsive Layout Preparation**
  Organize the CSS grid, flexbox structure, and media queries to support all screen dimensions, from desktop down to mobile devices.

* **Multiple Testimonial Layouts & Cards**
  Design and style multiple distinct testimonial card variants (speech bubbles, avatar cards, highlight review cards) and a multi-profile slider structure.

## Project Structure

* **Homepage (`index.html`)**
  The primary HTML document containing the various testimonial cards, user reviews, ratings, and profile information layout.

* **Styles (`css/style.css`)**
  Contains custom CSS styling, card positioning, flexbox layout, responsive media queries, typography, and visual enhancements.

* **Assets (`assets/`)**
  Directory containing project assets including `favicon/`, `logo/`, `open-graph/`, `profile-pictures/`, and `project-preview.png`.

## How to Use

1. Clone or download this repository.

```bash
git clone https://github.com/aditnurdiansyah/testimonial-cards
```

2. Navigate to the project folder.

```bash
cd testimonial-cards
```

3. Open `index.html` in your browser.

4. Customize the testimonials, avatar images, and styling based on your product needs.
